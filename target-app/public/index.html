Fault injection

Force the next request into a condition, then replay or browse to see how it is handled. Sticky modes stay until reset; the others clear themselves after one request.

ModeWhat the app doesHow replay classifies it
not_foundMember lookup returns no recordBusiness outcome — a legitimate answer, exit 0
permission_deniedOperator lacks rights for the recordBusiness outcome, exit 0
validationForm rejects the submitted valueBusiness outcome, exit 0
app_errorHTTP 500 with APPLICATION ERROR - REF 0x5A2Failure — exit 1
session_expiredBounces back to the sign-on pageFailure, recoverable by re-login
interstitialInjects a splash page before the real oneAbsorbed by the settle step
slowDelays the responseAbsorbed by timeouts, or exit 1 on timeout

Run the demo

Define the shorthand once per terminal, from the repository root on Node 20:

nvm use 20
ledgerhand() { npx --no-install tsx src/cli/index.ts "$@"; }

Replay with no model in the loop

ledgerhand replay capabilities/member-savings-balance.v1.json --input memberId=10001

Watch the browser do it

ledgerhand replay capabilities/member-savings-balance.v1.json --input memberId=10001 --headed

Same artifact against beta

ledgerhand replay capabilities/member-savings-balance.v1.json --input memberId=10001 --tenant beta

Agent-facing catalog

ledgerhand catalog tools
ledgerhand invoke member.savings_balance.lookup --input '{"memberId":"10001"}'

Escalate to a human at the irreversible step

ledgerhand replay capabilities/subaccount-open.v1.json --input memberId=10001 --operator

Record a new capability (needs ANTHROPIC_API_KEY)

ledgerhand discover --goal "Look up a member savings balance" \
  --url http://127.0.0.1:4599/t/alpha/msc/login --input memberId=10001

Exit codes

  • 0 — success, or a declared business outcome such as member not found
  • 1 — failure; the step, expected action and observed page are printed
  • 2 — escalated to a human and left unresolved

Every run writes evidence to evidence/runs/<runId>/: an ordered JSONL log, screenshots and DOM snapshots at failures, and the exact artifact as executed.
